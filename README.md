# AI Chat Widget (HealthyLine)

Интеллектуальный виджет чата с поддержкой интеграции n8n, поиска заказов (My Orders), сравнения серий ковриков HealthyLine (PEMF / Far Infrared / Photon / Gemstones) и каталога Best Sellers.

---

## 🚀 Как использовать проект (для не-программистов)

Всё настроено автоматически! Вам нужно выполнить всего 2 простых действия:

1. **Скачать архив**: В верхнем правом меню интерфейса Google AI Studio нажмите иконку настроек / меню и выберите **«Export as ZIP»** (или «Download ZIP»).
2. **Залить на GitHub**: 
   - Удалите старые файлы в вашем репозитории `terryogle/ai-chat-healthyline`.
   - Распакуйте скачанный ZIP и скопируйте все файлы и папки в ваш репозиторий.
   - Сделайте коммит и `git push` в ветку `main` (или `master`).

3. **Готово!** Робот GitHub Actions (`.github/workflows/build.yml`) автоматически:
   - Установит зависимости через `npm install`.
   - Проверит TypeScript и соберет проект `npm run build`.
   - Создаст и обновит папку `dist` прямо в вашем GitHub-репозитории.

---

## 🛠 Локальная разработка и сборка (если нужно)

Если вы запускаете проект на компьютере:

```bash
# 1. Установка всех зависимостей
npm install

# 2. Запуск локального сервера разработки
npm run dev

# 3. Полная компиляция и сборка проекта в папку dist
npm run build
```

## 📂 Структура проекта
- `src/components/` — Vue-компоненты чата (Chat, SeriesComparison, ProductCatalog, OrderAuthCard и др.).
- `src/composables/` — логика чата, сессий и интеграции с n8n webhook.
- `src/data/` — базы данных товаров и сравнительных характеристик ковриков.
- `resources/` — локальные картинки, иконки и логотипы.
- `.github/workflows/build.yml` — скрипт автоматической сборки на GitHub.
