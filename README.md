# AI Chat Widget (HealthyLine)

Этот проект представляет собой полностью самодостаточный виджет чата для n8n.

## Использование
1. Скачайте проект (используйте кнопку "Export to ZIP" в интерфейсе AI Studio).
2. Загрузите содержимое в ваш репозиторий GitHub.
3. GitHub Actions автоматически соберет проект при каждом пуше в `main` ветку.
4. Готовый билд (папка `dist`) будет закоммичен обратно в репозиторий.
5. Подключите скрипты из папки `dist` к вашему сайту.

## Сборка
Проект использует Vite + TypeScript.
- `npm install` — установка зависимостей.
- `npm run build` — сборка проекта.
